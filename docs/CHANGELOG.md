## 2026-10-27

一整天从「只有环境自检」推进到「第一个流程能在真机上跑通」。

### 新增功能

**窗口与设备**
- 窗口绑定 `tools/pick_window.py`：枚举游戏窗口 → 选择 → 写入实例配置；
  支持 `--list` / `--remove` / `--rebind`。绑定后回读验证，确认能找到同一个窗口。
- 实例配置改为一实例一文件 `configs/instances/<实例名>.yaml`，多开时互不干扰。
- 截图命令 `tools/capture.py`：后台截图存 PNG，报告亮度统计与耗时。
- 设备层支持后台点击（`PostMessage`）与按住时长（`hold_ms`），点击前校验坐标在客户区内。

**模板体系**
- 模板改为按页面分文件夹：`assets/pages/<页面>/` 下同时放 `templates.yaml` 和模板图。
- 模板工作台 `tools/workbench.py`：一个窗口里完成截图、框选生成模板、核对/调整 roi。
  模板列表按页面分组，首次保存自动采样 12 帧定阈值（最低分 − 0.05）。
- 命中报告 `tools/whereami.py`：给一张画面（现场或历史截图），报告所有模板的得分、
  位置、是否达标，并输出页面判定结论。
- 页面自检 `tools/check_pages.py`：检查页面定义引用的模板是否存在、图片是否齐全、
  有没有纯色模板。发现问题退出码 1，可用于提交前拦截。

**识别与页面**
- 识别层 `core/vision/`：`roi`（归一化换算）、`match`（模板匹配）、
  `io`（读写图，兼容中文路径）、`quality`（纹理检查）。
- 页面层 `core/page/`：`Page` 基类（key / page / anchors / priority）、`El` 元素、
  注册表与路由。锚点全部命中才算页面成立，多页面同时命中时按优先级取最高的。
- 已定义两个页面：`home`（庭院，锚点=式神录+好友）、`guild`（阴阳寮，锚点=结界+寮信息）。

**会话与流程**
- 会话层 `core/session/`：`Session` 提供 7 个原子动作
  `shot` / `detect` / `require` / `expect` / `wait_any` / `locate` / `tap`。
  刻意不提供 `goto` / `back` / `seen`——能由这些组合出来的就不单独写。
- 拟人化 `core/humanize/`：点击位置按正态分布在模板矩形内随机（中心密、边缘疏），
  按压时长随机 50~120 毫秒；`delay()` 提供随机间隔（暂未接线）。
- 第一个流程 `game/flows/enter_guild.py`：确认在主界面 → 点阴阳寮 → 等阴阳寮界面出现。
- 流程运行器 `tools/runner.py`：自动提权、日志显示在窗口内，预期失败只显示
  「原因 + 建议」，真 bug 才打堆栈。
- 异常分三层：`ConfigError`（改文件才行）/ `SessionError`（换一帧可能就好）/
  `DeviceError`（环境问题）。每个异常带 `hint`，说明大概率原因和排查方向。

### 修复

- **`PrintWindow` 全部返回 0** → 改用 `GetDC + BitBlt` 截图，并验证遮挡时也能取到画面。
- **`load_image` 对不存在的文件抛 `FileNotFoundError`**，而不是文档承诺的返回 `None`
  ——导致「模板图缺失」那条友好报错永远走不到。已修。
- **`tools/doctor.py` 引用已删除的 `paths.TEMPLATES_DIR`**，自模板迁移起就一直崩溃，
  只是没人跑。已改为检查 `PAGES_DIR` 并列出已有页面。
- **纯色模板会「匹配到任何地方」**：`TM_CCOEFF_NORMED` 对常数模板返回 1.0，
  存下去会在运行时静默点到错误位置。现在保存模板时检查纹理，纯色直接拒绝；
  `check_pages` 同样检查。
- **页面名可路径穿越**：`../outside` 会逃出 `assets/pages/`，`a/b` 会变成子目录。
  现在页面名/元素名只允许字母数字下划线横线，`paths.page_dir` 还有一道兜底。
- **比例校正的整数取整**：原来按 `round(高度×16/9)` 算宽度，只有高度能被 9 整除时
  才能凑出精确 16:9，否则会先改窗口、再因为校验不过而报错。现在比例不对时
  固定改成 1280×720。
- **运行器未判 `instances.load()` 返回 `None`**：配置被外部删除时抛出 `AttributeError`，
  界面无提示。已加判空并刷新下拉框。
- 清理了 4 个文件的 UTF-8 BOM（批量改写时误写入）、5 处未使用的 import、3 处死代码。

### 重构

- 设备层从 ctypes 改为 **pywin32 + psutil** 实现（`core/device/desktop.py`）。
- 取消 `app/` 层，代码直接位于 `program/backend`。
- 抽出公共模块：`core/vision/io.py`（读图写图，消掉 7 处重复）、
  `tools/_console.py`（中文对齐，消掉 3 份 `pad` 实现）。
- 移除会话层里能组合出来的方法：`goto`、`back`、`seen`；删除无调用者的 `NotSupported`。
- 模板改名：`home/friends` → `home/friends_entry`，`home/shop` → `home/shop_entry`，
  统一成「入口加 `_entry` 后缀」的命名约定。

### 已知问题（尚未处理）

- **窗口位置变化会导致绑定错账号**：`match_index` 是按屏幕位置排序后的序号，
  把两个窗口上下位置换了，同一个实例可能指向另一个账号。目前靠「窗口位置固定」维持。
- **800×450 的窗口不会被自动改成 1280×720**：它们是精确 16:9，不触发校正。
  但模板是在 1280×720 下采的，需要手动拉窗口。
- **换庭院皮肤会导致静态模板失配**：底部导航栏会整体位移十几像素，
  0.95 阈值的模板得分掉到 0.90~0.93。已约定固定使用当前皮肤。
- 重复代码尚未合并：`_arg` 参数解析（2 份）、`expect`/`wait_any` 的轮询循环、
  「读实例 → 建设备」（4 处）。
